# Phases and Methodology

## Delivery phases
0. Project setup (rules, CI, design system)
1. Discovery & design
2. Foundation (auth, RBAC, audit, admin shell, import)
3. Intake & Forms Engine
4. Classifier, Evaluation, Routing
5. Inspection, Fees, Compliance
6. Records, Notifications, polish
7. QA, UAT, Deploy
8. Warranty (6 months)

## Agile approach
Iterative sprints; each completed function updates the living project plan (todos + changelog).

## RACI (summary)
