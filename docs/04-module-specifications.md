# Module Specifications (Phase I)

1. **Application & Intake** — wizard, uploads, tracking, Citizens stub
2. **Unified Forms** — QMS-36/37+ dynamic schemas, print templates
3. **Permit Classifier** — Simple / Complex / Highly Technical
4. **Evaluation & Routing** — QMS-61/62/63/64, time tracking
5. **Inspection** — QMS-38/39, O-03, QMS-65, DPWH 77-006-E
6. **Payment (basic)** — G-02 Order of Payment, LGU/BFP/DPWH fee split, CTO stub
7. **Compliance** — G-03, G-04, appeal support
8. **Records** — G-01, O-02, E-series, G-05, G-06
9. **Notifications** — in-app + email templates
10. **Audit** — `/modules/audit` viewer
11. **Admin** — all master data CRUD + import/export
